# ANWB Energie demo app

Mobile web replica of the ANWB Energie app for an Amplitude platform demo. Single static page, no build step.

- Amplitude project 886391 (Analytics, Session Replay, Web Experiment, Guides & Surveys via the Unified Script, Feature Experiment via the Experiment JS client)
- "Iris" in-app assistant emits Agent Analytics events
- Gear icon opens demo controls (experiment variants, relationship number linked, products held)
- Open with `?amp_device_id=<web device id>` to simulate the anwb.nl QR handoff

Deploy: GitHub > Settings > Pages > Deploy from branch `main`, folder `/ (root)`. See `DEMO-GUIDE.md` in the package for Amplitude setup.
